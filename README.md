# 🏃 Personal Fitness Performance Analyzer

A time-series analytics system that evaluates running performance trends using NumPy and Pandas.

This project simulates and analyzes fitness data to detect:

- Speed improvement trends
- Performance plateaus
- Weekly and monthly progress
- Correlation between weight and speed

---

## 📊 Project Overview

This project demonstrates:

- Time-series data preprocessing
- Feature engineering
- Statistical analysis using NumPy
- Rolling window trend detection
- Rule-based intelligence system for performance insights

It simulates 60 days of structured fitness data and builds an analytical pipeline similar to real-world health-tech systems.

## 🚀 How to Run

1. Install dependencies:


pip install -r requirements.txt


2. Generate data:


python src/data_generation.py


3. Run analysis:


python src/analysis.py


4. Run trend detection:


python src/trend_detection.py
